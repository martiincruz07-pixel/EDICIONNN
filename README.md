# Motion graphics con Remotion

Carpeta de trabajo para hacer animaciones con código usando [Remotion](https://www.remotion.dev).

- `.claude/skills/`: skills oficiales de Remotion (de `remotion-dev/skills`) para Claude Code.
- `skills-lock.json`: registro de qué versión de cada skill está instalada.

Para actualizar las skills: `npx skills update -y`
